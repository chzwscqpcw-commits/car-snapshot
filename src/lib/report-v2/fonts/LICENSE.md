# Report fonts

Bundled for the server-rendered PDF report (`src/lib/report-v2`). Latin subset
woff2 files, downloaded from Google Fonts on 2026-10-12. All three families are
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which permits bundling and embedding them in documents.
