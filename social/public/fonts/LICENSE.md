# Report fonts

Bundled for the server-rendered PDF report (`src/lib/report-v2`). Latin subset
woff2 files, downloaded from Google Fonts on 2026-10-12. All three families are
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which permits bundling and embedding them in documents.

- Geist, Geist Mono: © Vercel (https://github.com/vercel/geist-font)
- Instrument Serif: © The Instrument Serif Project Authors
  (https://github.com/Instrument/instrument-serif)

`Geist-Bold.ttf` is a static weight-700 instance of `Geist.woff2`, made with
fontTools on 2026-10-31 for the alert emails' plate image (`src/lib/plate-image.tsx`),
which draws with satori and cannot read woff2. Same licence.
